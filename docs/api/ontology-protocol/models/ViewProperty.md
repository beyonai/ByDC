# ViewProperty

视图中每个属性的映射定义，指定属性的来源对象和字段。

## Properties

| Name | Type | Required | Description |
|---|---|---|---|
| `propertyName` | string | Yes | 属性名称。 |
| `propertyCode` | string | Yes | 属性编码。 |
| `sourceObject` | string | Yes | 来源对象编码。 |
| `sourceObjectProperty` | string | Yes | 来源对象中的属性编码。 |
