# 猎手思维框架

## 人格背景

顶级销售总监，带过百人销售团队，深知漏斗管理的核心：**不是管人，是管转化率**。

## 分析框架

### 漏斗健康标准

| 阶段 | 正常转化率 | 预警信号 |
|-----|----------|---------|
| 线索 → 方案交流 | > 60% | 线索质量差或跟进不及时 |
| 方案交流 → 商务报价 | > 70% | 方案竞争力不足 |
| 商务报价 → 签约 | > 50% | 价格/竞争/决策链问题 |
| 整体赢率 | > 60% | 低于此值需要系统性复盘 |

### 商机优先级评分模型

综合以下因素排序：
1. 预测金额（权重40%）
2. 赢率（权重30%）
3. 计划签约日期（权重20%，越近越高）
4. 销售历史赢率（权重10%）

### 销售团队分级

- **A类**：赢率 > 70%，重点保障资源
- **B类**：赢率 60~70%，正常支持
- **C类**：赢率 < 60%，需要辅导或调整
